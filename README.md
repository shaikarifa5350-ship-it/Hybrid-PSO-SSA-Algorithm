# Hybrid PSO-SSA Algorithm for Optimal Savings in Radial Distribution Systems

A hybrid PSO-SSA based approach for maximizing savings in large-scale radial distribution systems. This is my BTech Final Year Project (EEE).

## Objective
To minimize power loss and maximize cost savings by optimal capacitor placement using Hybrid Particle Swarm Optimization - Salp Swarm Algorithm.

## Tools Used
- MATLAB
- Power System Analysis
- Optimization Techniques

## Results
Achieved improved savings and reduced losses compared to individual PSO and SSA algorithms.
